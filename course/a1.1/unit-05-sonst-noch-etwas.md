## Chunks from this unit

| Chunk | Meaning | Note |
|---|---|---|
| Was möchten Sie gerne? | What would you like? | formal shop |
| Ich hätte gerne … | I’d like … | ≈ *Ich möchte …* (booklet: *hätte gern* a bit more formal) |
| Haben Sie Äpfel? | Do you have apples? | |
| Ich nehme die zwei … hier. | I’ll take these two … here. | |
| Hier, probieren Sie mal! | Here, try! | formal |
| Das dort / das hier | that one there / this one here | gender: *der/die/das da* |
| Das ist kein Brot. | That’s not bread. | *kein/keine* |
| Was kostet das Brötchen? | How much is the roll? | sg → *kostet* |
| Was kosten die Kekse? | How much are the cookies? | pl → *kosten* |
| Das ist zu teuer. | That’s too expensive. | |
| Das macht dann X Euro. | That comes to X euros. | |
| Stimmt so, danke. | Keep the change, thanks. | |
| Sonst noch etwas? | Anything else? | sales talk |
| Wie viele … hätten Sie gerne? | How many … would you like? | countable |
| Wie viel kostet …? | How much does … cost? | uncountable / price |
| viel Obst / viele Würste | much fruit / many sausages | *viel* vs *viele* |
| Auf Wiedersehen! / Schönen Tag noch! | formal goodbye / have a nice day | also *Schönen Abend!* · *Schönes Wochenende!* |

**Fruit/veg (with plural):** *die Erdbeere → die Erdbeeren* · *der Apfel → die Äpfel* · *die Birne → die Birnen* · *das Obst* (no plural; use *die Früchte*) · *das Gemüse* (plural rare)

**Footnotes:** *doch* answers a negative question by contradicting it · *ja* can be a modal particle (reproachful “as you know”) · *die da* agrees with noun gender

## Drill ladder

1. Ich hätte gerne Erdbeeren. / Haben Sie Äpfel?
2. Das ist kein Brot. / Das sind keine Kartoffeln.
3. Was kostet das Brötchen? / Was kosten die Kekse?
4. Kennen Sie keine …? → Doch!
5. Wie viel Wasser? / Wie viele Würste? · Sonst noch etwas?
6. Trap: *kein* vs *keine* · *viel* vs *viele* · *ja* on a negative question when you mean *doch*
