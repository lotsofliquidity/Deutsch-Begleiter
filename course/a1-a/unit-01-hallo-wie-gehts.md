# A1.A Unit 1 — Hallo, wie geht’s?

**Source:** `courses/a1.1/` + LÖSUNGEN · **Setting:** Im Flugzeug · **Met:** 2026-09-16 · **Ingested**

## Chunks from this unit

| Chunk | Meaning | Note |
|---|---|---|
| Hi! / Hallo! / Moin / Na? / Hallihallo! | informal hellos | booklet greeting list |
| Hallo! Wie geht’s? | Hello! How are you? | = *Wie geht es dir?* |
| Gut, und dir? | Good, and you? | **dir**, not *du* |
| Auch gut, danke! | Also good, thanks! | |
| Woher kommst du denn? | Where are you from? | *denn* = modal particle |
| Ich komme aus Australien. | I’m from Australia. | don’t drop **aus** · also *Wo kommst du her?* |
| Und du? | And you? | |
| Sieht man das nicht? | Can’t one/you see that? | *man* ≠ *der Mann* |
| Na klar. | Of course. | |
| Wo ist denn mein …? | Where’s my …? | *denn* again |
| Danke für … | Thanks for … | e.g. *Danke für die Erdnüsse* |
| Mahlzeit! | Enjoy your meal! / lunch greeting | regional |
| Guten Morgen! | Good morning! | also appears informally here |
| Du sprichst aber gut Deutsch! | You speak German really well! | *sprechen*: *du sprichst* |
| Welche Sprachen sprichst du? | Which languages do you speak? | also *Was sprichst du?* |
| Ich spreche fließend … | I speak … fluently | |
| Etwas Französisch. | A little French. | *etwas* + language |
| Wie heißt du eigentlich? | What’s your name, by the way? | *eigentlich* ≈ by the way |
| Ich heiße Katie und du? | My name is Katie and yours? | |
| Mein Spitzname ist … | My nickname is … | |
| Schön dich kennenzulernen. | Nice to meet you. | also *Freut mich.* |
| Was machst du hier? | What are you doing here? | |
| Da drüben … | Over there … | |
| Ach ja, stimmt. | Oh yes, that’s right. | |
| Viel Spaß in … | Have fun in … | |

**Footnotes (flavour):** *Was geht ab?* (colloquial) · *geil* (awesome; original meaning rude) · *ick* (Berlin *ich*) · modal particles *ja*, *doch*

## Drill ladder

1. Hallo! Wie geht’s? → Gut, und dir?
2. Woher kommst du denn? → Ich komme aus …
3. Sieht man das nicht?
4. Welche Sprachen sprichst du? → Ich spreche …
5. Wie heißt du eigentlich? → Schön dich kennenzulernen.
6. Trap: *Gut, und du?* · *man* vs *Mann* · *eigentlich* ≠ “actually”
