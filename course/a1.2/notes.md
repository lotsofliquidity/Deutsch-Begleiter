# A1.2 notes

Grammar spine for A1.2. A1.1 stays in `course/a1.1/notes.md`.

## Adjective strength (U1)

| Strength | Words | Example |
|---|---|---|
| high | *sehr, total, echt, wirklich* | *Berlin ist wirklich toll.* |
| low | *ziemlich, ein bisschen, nicht so* | *nicht so hell* |
| negative “very” | *gar nicht, überhaupt nicht* | *gar nicht toll* |

*Heute habe ich gar keine Zeit.* · *Das ist wirklich schade.*

## Präteritum *sein* / *haben* (U1)

Spoken past for these two. Other verbs wait for the perfect.

| | sein | haben |
|---|---|---|
| ich | **war** | **hatte** |
| du | warst | hattest |
| er/sie/es | **war** | **hatte** |
| wir | **waren** | hatten |
| ihr | wart | hattet |
| sie/Sie | **waren** | hatten |

*ich* = *er/sie/es*. *wir* = *sie/Sie*.

*Wo warst du gestern?* · *Ich hatte eine kleine Wohnung.*

## Gefallen (U1)

| Ask | Answer |
|---|---|
| *Wie findest du X?* | *Ich finde sie/es schön.* / *X ist schön.* |
| *Wie gefällt dir X?* | *X gefällt mir sehr gut.* |
| *Gefällt dir X?* | *Ja, sehr gut.* |

*mir* / *dir* here are fixed phrases until the end of A1.2.

## Es gibt (U1)

*Es gibt* stays singular. The thing after it is accusative (*einen* / *ein* / *kein* …).

*Es gibt einen Tisch.* · *Es gibt ein Sofa.* · *Es gibt kein Sofa.* · *Es gibt viele Zimmer.*
*Gibt es einen Tisch?* · *Was gibt es in Berlin?*

## sehen / lesen (U1)

Vowel change in *du* and *er*.

| | sehen | lesen |
|---|---|---|
| ich | sehe | lese |
| du | **siehst** | **liest** |
| er/sie/es | **sieht** | **liest** |
| wir | sehen | lesen |
| ihr | seht | lest |
| sie/Sie | sehen | lesen |

*lesen*: stem ends in *s*, so *du* has no extra *s*.

## müssen (U1)

| | |
|---|---|
| ich **muss** | wir müssen |
| du musst | ihr müsst |
| er/sie/es **muss** | sie/Sie müssen |

Necessity. Conjugated *müssen* in position 2; bare infinitive at the end.
Separable verbs stay whole there: *Ich ziehe die Schuhe aus.* → *Ich muss die Schuhe ausziehen.*

## Rooms and chores (U1)

Rooms and furniture: see the unit file. Plurals only where the booklet prints them.

Chores: *aufräumen · putzen · wischen · staubsaugen · spülen/abwaschen · Wäsche waschen · Blumen gießen · Müll rausbringen.*

## Numbers from 100 (U1)

*einhundert … neunhundert* · *eintausend* · *zehntausend* · *(ein)hunderttausend*
*eine Million* / *zwei Millionen* · *eine Milliarde* / *zwei Milliarden*

Inside the number, ones still come before tens: *zweihundertfünfundvierzig* (245).
